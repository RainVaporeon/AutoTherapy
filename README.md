# AutoTherapy
Your own personal ai assistant that always listens to your problems!

# Requirements
something that has python!

# How to run

## Windows
Run `python therapy.py` in your terminal with the file in the same folder!

## Linux
First, make the file executable:
`chmod +x ./therapy.py`
and then run the file!
`./therapy.py`

# How to exit
Press the simple combo of Ctrl-C!
